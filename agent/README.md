# Glovebox agent

LiveKit voice agent. Conversation only: every rule, number and permission comes from `/api`.

## Setup

```
cp .env.example .env      # fill in the keys
uv sync
```

## Run

```
uv run --env-file .env python -m glovebox_agent.main dev       # join LiveKit Cloud; test in the Agents Playground
uv run --env-file .env python -m glovebox_agent.main console   # talk in the terminal
```

The API must be running (`cd ../api && pnpm dev`). In the playground there is no caller ID, so the
agent asks for the sandbox's 4-digit demo code. A browser participant can skip that by setting its
metadata to `{"demo_code": "1234", "seed_key": "tommy"}`.

## Test

```
uv run pytest                                                      # unit tests
uv run --env-file ../api/.env pytest tests/test_api_integration.py # tools against a running API, no keys
uv run --env-file .env pytest -m live                              # stories and spoken amounts, real keys
```

Live runs save transcripts to `../evals/transcripts/`.

## Layout

- `glovebox_agent/main.py`: worker entry, caller resolution, session (Deepgram Nova-3, Gemini, TTS, turn detector)
- `glovebox_agent/agent.py`: LiveKit agents and tool wrappers
- `glovebox_agent/tools.py`: tool logic (refs, repeated logs, readback check, error policy)
- `glovebox_agent/session.py`: per-call state
- `glovebox_agent/prompt.py`, `prompts/system.md`: system prompt and greeting
- `glovebox_agent/api_client.py`: the only HTTP code
- `glovebox_agent/api_models.py`: generated by `scripts/generate_models.sh`; do not edit
